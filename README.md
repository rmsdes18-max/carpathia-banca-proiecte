## Înlocuire logouri
Pune fișierul nou cu **același nume** în `assets/` (PNG cu fundal transparent recomandat):
- `assets/logo-ccb.png` — Casa de Comerț Balcanică (hero + footer)
- `assets/logo-neurom.png` — Neurom (footer)
- `assets/og-cover.png` — imaginea de previzualizare la share
